## 🏗 Architecture Overview

### Production Process Flow
```
1. Create DRAFT process → Add results/losses → Confirm
2. Confirmation triggers:
   - WIP balance validation
   - Material deduction (via BOM calculation)
   - Product addition to WIP
   - Status change to CONFIRMED
   - Process becomes read-only
```

### WIP Stock Integration
```python
# During confirmation:
_apply_results_to_wip()  # Deduct materials, Add products
_apply_losses_to_wip()   # Deduct lost materials
```
